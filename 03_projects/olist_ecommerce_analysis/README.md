# Olist E-commerce Data Analysis Project

## 📌 Project Overview
This project analyzes the Olist Brazilian e-commerce dataset to identify
high-value customer behavior and growth opportunities.

The analysis focuses on:
- Revenue and order trends
- Customer purchase behavior
- LTV (Lifetime Value) distribution
- Pareto principle (top customers’ revenue contribution)
- First purchase behavior of high-value customers
- Regional distribution of high-value customers
