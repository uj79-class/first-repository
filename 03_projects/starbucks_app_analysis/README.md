# Starbucks App Offer Failure Analysis

## 1. 프로젝트 배경
스타벅스 앱에서는 다양한 프로모션 오퍼가 고객에게 제공되지만,
조회(Viewed) 이후 실제 구매 또는 완료(Completed)로 이어지지 않는 경우가 빈번하다.

본 프로젝트는 단순 전환율 분석을 넘어,
**오퍼를 인지한 이후에도 행동으로 이어지지 않은 실패 구조**에 초점을 맞추었다.

---

## 2. 데이터 소개
- Starbucks 공개 데이터 (Udacity 제공)
- 데이터 구성:
  - profile.json : 고객 인구통계 정보
  - portfolio.json : 오퍼 속성 정보
  - transcript.json : 이벤트 로그 (Received / Viewed / Completed / Transaction)

### 분석 단위
- JSON 이벤트 로그를 정합하여  
  **person × offer 단위의 분석 데이터셋 구성**

---

## 3. 문제 정의
- 실패 정의:
  - Viewed = True & Completed = False → Drop-off
- 분석 목표:
  - 어떤 고객·어떤 오퍼·어떤 시점에서 실패가 집중되는가?

---

## 4. 분석 접근
- 오퍼 라이프사이클 퍼널 분석
- 오퍼 속성 단독 분석 (유형 / 난이도 / 기간 / 채널)
- 실패 세그먼트 분석
  - 저소득 × 고난이도 오퍼
  - 신규 고객 × 오퍼 지속 기간
- 카이제곱 검정을 통한 구조적 차이 검증
- 코호트 리텐션 분석
- 이탈 예측 모델
  - Logistic Regression
  - SHAP 기반 모델 해석

---

## 5. 주요 인사이트
- 오퍼 실패는 고객 의지 문제가 아니라  
  **오퍼 조건 × 고객 맥락 × 타이밍의 상호작용 문제**
- 신규 고객은 동일한 오퍼 조건에서도 이탈 확률이 높음
- 고난이도 오퍼는 학습된 고객에게만 효과적
- Viewed 이후 미완료는 의미 있는 실패 신호로 활용 가능

---

## 6. 비즈니스 시사점
- 신규 고객 대상 단기 성공 경험 중심 오퍼 설계
- 고난이도 오퍼의 타겟팅 정교화
- 오퍼 기대 형성 단계(Viewed)에서의 조건 안내 개선

---

## 7. 한계 및 향후 과제
- 관측 데이터 기반 분석으로 인과 관계 추론에는 한계
- 향후 A/B 테스트 기반 오퍼 실험 필요
