# first-repository
모두의 연구소_데이터 분석가 4기 : 수업, 실습, 프로젝트 결과물 아카이브

수업/실습과 프로젝트 결과물을 정리한 레포지토리입니다.  
(Jupyter Notebook 중심) 과제/퀘스트/프로젝트를 폴더별로 정리했습니다.

## 폴더 구조
- `01_homework/` : 주차별 과제 노트북
- `02_quests/` : 퀘스트 결과물(노트북/리포트)
- `03_projects/` : 데이터 분석 프로젝트 모음
  - `taxi/` : Taxi 데이터 분석
  - `car/` : Car 데이터 분석 (ver2 포함)
  - `fraud/` : Fraud 탐지/분석 (ver2 포함)
  - `datathon_app/` : 데이터톤(App market analysis) 결과물

## 대표 결과물 바로가기
> 아래 링크는 “클릭하면 열리는” 목차 역할을 합니다.

### Projects
- Fraud 프로젝트: `03_projects/fraud/`  
  → 이상 거래 패턴 탐색 및 EDA 중심 분석
- Car 프로젝트: `03_projects/car/`  
  → 차량 데이터 분석 및 ver2 개선
- Taxi 프로젝트: `03_projects/taxi/`  
  → 수요/요금 패턴 분석
- Datathon(App): `03_projects/datathon_app/`  
  → 앱 마켓 데이터 분석 및 인사이트 도출

### Homework / Quests
- Homework 모음: `01_homework/`
- Quests 모음: `02_quests/`
